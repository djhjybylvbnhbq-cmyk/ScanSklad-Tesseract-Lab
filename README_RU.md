# ScanSklad Tesseract LAB v0.1 — отдельный тест русских адресов

**НЕ обновление ScanSklad v2.0.** Это отдельный APK с идентификатором `com.scansklad.tesseractlab`, который устанавливается рядом с обычным ScanSklad и не имеет доступа к его данным.

## Зачем нужен

Сравнивает OCR двух движков на **одной и той же области кадра внутри красной рамки**:

- **Tesseract 5 (rus+eng)** через Tesseract4Android — офлайн OCR с русской и английской языковыми моделями;
- **ML Kit Latin** — прежний OCR из Android v2.0, без правил подстановки/нормализации.

В интерфейсе показываются оба **сырых** текста и время распознавания, у Tesseract также показывается оценка уверенности. Эти проценты не гарантируют правильность. Тест не заменяет и не отправляет складские результаты.

Всё запускается локально, разрешение `INTERNET` в AndroidManifest отсутствует. Языковые модели загружаются только **GitHub Actions во время сборки APK** и включаются в APK. Никаких запросов к облачному OCR при эксплуатации.

## Получить APK без Android Studio

1. Создайте **новый репозиторий** GitHub `ScanSklad-Tesseract-Lab`. НЕ используйте уже работающий `ScanSklad`.
2. Распакуйте ZIP и загрузите файлы/папки **изнутри** распакованной папки в корень нового репозитория: `app`, `scripts`, `.github`, `build.gradle`, `settings.gradle` и остальные.
3. Если скрытая папка `.github` не загрузилась, откройте **Actions → set up a workflow yourself**. Создайте `.github/workflows/build-apk.yml` и вставьте **весь текст** файла `WORKFLOW_ДЛЯ_КОПИРОВАНИЯ.txt`. Убедитесь, что в начале файла есть строка `on: [push, workflow_dispatch]`.
4. Нажмите **Commit changes**. На **Actions** появится **Build Tesseract OCR Lab APK**. В GitHub Actions будут скачаны официальные `rus.traineddata` и `eng.traineddata` с `tesseract-ocr/tessdata_fast`.
5. После зелёной сборки зайдите в выполненный workflow и скачайте **ScanSklad-Tesseract-Lab-debug-APK** из раздела **Artifacts**. Распакуйте ZIP и установите `app-debug.apk` на телефон.
6. Откройте **ScanSklad Tesseract LAB**, разрешите камеру и дождитесь сообщения **«Модель Tesseract готова»**.

Если сборка красная — пришлите скриншот **красного шага в build**, а не только красный значок на странице Actions.

## Проверка

1. Поместите **одну строку адреса** внутрь красной рамки и нажмите **СКАНИРОВАТЬ**. По умолчанию автосканирование отключено. Можно включить его кнопкой «АВТО: ВКЛ», тогда сканер будет периодически обновлять результаты.
2. Сравните Tesseract и ML Kit с настоящей этикеткой. Впишите правильное написание в поле внизу экрана, например `142/П10/1`.
3. Нажмите **ЗАПОМНИТЬ ТЕСТ**. Повторите на нескольких этикетках, включая `142/П1/1`, `142/П10/1`, `142/Л10/1`, `162/шкаф8`, `148/сейф2`.
4. Нажмите **ОТПРАВИТЬ ОТЧЁТ**, чтобы поделиться результатами сравнения. Отчёт сохраняется локально между запусками.

Для честного сравнения делайте несколько тестов каждого адреса в разных условиях освещения. **Никаких автоматических замен П ↔ 1 и Л ↔ 1 в тестовой версии нет.**

## Что проверено, а что пока нет

Проверены структура исходников, согласованность Android resource ID, синтаксис XML и shell-скрипта, конфигурация workflow. **APK не собран и не проверен на физическом Android** в моей среде: тут нет Android SDK и сетевого доступа для скачивания Gradle/моделей. Первая GitHub-сборка — часть испытаний.

## Источники

- Tesseract4Android: https://github.com/adaptech-cz/Tesseract4Android — Android-обёртка для Tesseract, Apache 2.0. Dependency: `cz.adaptech.tesseract4android:tesseract4android:4.9.0`.
- Official tessdata_fast: https://github.com/tesseract-ocr/tessdata_fast — модели `rus` и `eng` (Apache 2.0).
- ML Kit: https://developers.google.com/ml-kit/vision/text-recognition/v2/android
